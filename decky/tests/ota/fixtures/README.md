# TEST-ONLY fixtures

`TEST-ONLY-signing.key` / `.pub` are a throwaway Ed25519 keypair generated by
`tools/release/gen_keypair.py` so the tests can sign manifests. The private half is public
on purpose. It signs nothing real: the plugin trusts `inkterface_core/ota/trust.py`, which
holds the production public key (the private half is not in this repo). Never copy this key into trust.py.

`rfc8032_ed25519.json` is RFC 8032 section 7.1 (TEST 1, 2, 3, 1024, SHA(abc)), extracted
from the RFC text.
